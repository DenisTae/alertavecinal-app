# 🚨 AlertaVecinal — App Android

App Android del **Sistema de Alerta Comunitaria para la Prevención de Robos** (Equipo DHAAP). Permite a los vecinos reportar incidentes de inseguridad con su ubicación para que la policía pueda atenderlos con rapidez.

[![Última versión](https://img.shields.io/github/v/release/DenisTae/alertavecinal-app?label=versi%C3%B3n)](https://github.com/DenisTae/alertavecinal-app/releases/latest)
![Plataforma](https://img.shields.io/badge/plataforma-Android-3DDC84)

## 📱 Descarga
Escanea el código QR con la cámara de tu celular o descarga el archivo desde [**Releases**](https://github.com/DenisTae/alertavecinal-app/releases/latest).

## ⚙️ Instalación
1. Descarga el archivo `.apk` de la última versión.
2. Ábrelo y permite «instalar apps desconocidas».
3. Si Play Protect avisa, elige «Instalar de todas formas».
4. Inicia sesión y permite la ubicación «todo el tiempo».
